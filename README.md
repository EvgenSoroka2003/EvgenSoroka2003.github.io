# Економічна безпека Саудівської Аравії

Навчальний сайт. Автор — **Сорока Евгеній Вікторович**, здобувач освіти ступеня магістра, група **2-7м**. Рік створення — **2026**.

## Перегляд на комп’ютері

Розпакуйте ZIP і відкрийте `index.html` у браузері. Меню веде на аналітичну сторінку `analysis.html`. Встановлення програм, npm або збірка не потрібні.

## Публікація на GitHub Pages

1. Увійдіть у GitHub і створіть **публічний** репозиторій, наприклад `saudi-economic-security`. Публічний репозиторій підходить для GitHub Free.
2. Розпакуйте архів. Через **Add file → Upload files** завантажте **вміст архіву**, а не ZIP і не зовнішню папку. Файл `index.html` має бути безпосередньо в корені репозиторію, поруч із `analysis.html`, `styles.css` та папкою `assets`.
3. Збережіть файли кнопкою **Commit changes** у гілці `main`. Переконайтеся, що завантажено також порожній файл `.nojekyll`; за потреби створіть його через **Add file → Create new file**.
4. Відкрийте **Settings → Pages**. У розділі **Build and deployment** виберіть **Source: Deploy from a branch**, **Branch: main**, папку **/(root)** та натисніть **Save**.
5. Дочекайтеся завершення публікації. У **Settings → Pages** з’явиться адреса сайту та **Visit site**. Для репозиторію з наведеним ім’ям адреса матиме вигляд `https://ВАШ-ЛОГІН.github.io/saudi-economic-security/`.

Після публікації перевірте обидві сторінки, навігацію, графіки та завантаження PDF. Якщо бачите 404, перевірте розташування `index.html` у корені й налаштування гілки. Назви файлів і регістр літер слід зберегти.

Офіційна інструкція: [налаштування джерела публікації GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). Умови доступності й створення сайту: [GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Що містить архів

| Файл | Призначення |
| --- | --- |
| `index.html` | Головна сторінка, інформація про автора |
| `analysis.html` | Теоретична частина, показники, таблиці, графіки, загрози й висновки |
| `styles.css` | Оформлення та адаптація до різних екранів |
| `app.js`, `data.js` | Інтерактивні елементи й дані |
| `assets/report.pdf` | Оригінал навчально-аналітичної роботи |
| `assets/favicon.svg`, `assets/skyline.svg` | Локальні зображення сайту |
| `data/indicators.csv` | Таблиця показників для завантаження |
| `.nojekyll` | Публікація статичних файлів без обробки Jekyll |
| `README.md` | Ця інструкція |

## Дані та редагування

Зміст перенесено з роботи **«Аналіз_економічної_безпеки_Саудівської_Аравії_Сорока 2-7м»**. Період наведених даних — **2023–2025 роки**; окремі довгострокові порівняння мають інші роки. Значення відтворюють навчальне джерело й незалежно не оновлювалися до поточної дати. Дані різних років не утворюють єдиний часовий зріз. Інтегральний числовий індекс не обчислюється: вихідна методика не визначає ваг.

За вибором автора контактні дані не оприлюднено. Щоб його додати, відкрийте `index.html` у текстовому редакторі, знайдіть **«Контактні дані не оприлюднено»** та замініть на власну електронну адресу чи інший контакт. Для клікабельної адреси використайте посилання виду `<a href="mailto:ваша-адреса">ваша-адреса</a>` із реальною адресою.

Після редагування завантажте змінені файли в той самий репозиторій і збережіть зміни. GitHub Pages оновить сайт автоматично.

## Виконана перевірка

Перевірено відповідність показників PDF, арифметику, статуси, таблицю CSV, наявність усіх локальних файлів і внутрішніх переходів. JavaScript пройшов перевірку синтаксису та виконання в ізольованому тестовому середовищі: фільтри, меню, перемикання графіка й підготовка розрахунків до друку.

Візуальну перевірку у браузері не завершено через недоступність середовища перегляду. Адаптивні стилі передбачені, але перед здачею відкрийте сайт на комп’ютері й телефоні та перевірте вигляд. Частина зовнішніх статистичних сервісів повернула тимчасові помилки або обмеження запитів, тому доступність зовнішніх джерел підтверджено частково. Сайт і локальні матеріали працюють без цих сервісів.
